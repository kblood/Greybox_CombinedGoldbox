wilderness, quests, and Companion as partial where appropriate. Original CoAB save import and
export are explicitly unsupported: Greybox save version 2 is not a retail save bridge. Campaign
matrix evidence may be engine-proven without being a fully navigable UI sequence. “Verified” here
means this reproducible selected-folder release slice, not that every CoAB system, screen, branch,
campaign journey, or retail file format is complete.
