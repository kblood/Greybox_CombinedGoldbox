## Unknown or dynamically selected consumers

1. **Full ECL1–3 runtime PICTURE coverage:** the new SCENE-CENSUS-22 section gives an archive
   inventory and conservative static findings for all 22 blocks, with dynamic operands explicit.
   It does not establish a complete runtime denominator. That requires walking all five header entry points and all
   reachable GOTO/GOSUB/ON_GOTO/ON_GOSUB targets in each exact ECL archive, then separating static
   instruction reachability from runtime-guarded branches and actual campaign-reachable memory.
   A grep or first-EXIT disassembly is not sufficient. The engine `walkEclReachable` documentation
   explains this distinction.
2. **Dynamic source routing:** `PICTURE id` carries a number, while the actual archive is selected
   by the host and active disk; do not resolve every `<100` id to PIC1 or every `>=100` id to
   BIGPIC1 without the ECL/host contract. #57/#58 happen to resolve through the explicitly loaded
   PIC1 bank on the recorded Throtl host. Other scripts may use another `PICn`, a combined host
   map, or a branch-owned source.
3. **Combat reachability:** current CPIC Restyle inventory and runtime draw checks cover admitted
   identities but do not enumerate all natural ECL1/2/3 `LOAD_MONSTER`/combat rosters per disk.
   Full resolution must join reachable ECL inputs to exact `MON{disk}CHA` records and the actual
   encounter renderer's selected CPIC bank. Missing joins stay unknown, not “no Restyle needed.”
4. **Frame selection/animation:** the listed scene pilots explicitly pin frame 0. This register
   does not show that every ECL-selected animated frame or later scene transition is restyled.
5. **Layer/layout:** title compositor placement, dialogue canvas placement, in-game indexed layout,
   transparent mask, foreground UI/cursor and native pixel-scale are separate. Similar dimensions
   or a matching id do not establish a matching composed scene.
