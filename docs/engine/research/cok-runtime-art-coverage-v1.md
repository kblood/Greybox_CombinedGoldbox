# CoK runtime graphics coverage

The [coverage report](cok-runtime-art-coverage-v1.json) connects static game requests and
reviewed web consumers to canonical source locators, current runtime declarations, and the
Restyle registry. Its [consumer contract](cok-runtime-art-consumers-v1.json) pins the inputs
and explains the DOS-EGA, Amiga and Restyle behavior for each surveyed consumer. A changed
input requires review before updating its pin.

From the repository root:

~~~powershell
python tools/cok_runtime_art_coverage.py
python tools/cok_runtime_art_coverage.py --check
python tools/cok_runtime_art_coverage.py --check --asset-pack C:/GoldBoxImg/greybox-local-restyle-pack
python tools/test_cok_runtime_art_coverage.py
node tools/test_cok_runtime_art_coverage_schema.mjs
~~~

The default command prints a read-only summary. `--check` also compares the complete
generated bytes with the saved report. `--write` updates that report atomically after the
inputs pass. To independently reproduce the [combat receipt](cok-runtime-art-combat-sites-v1.json),
run `python tools/cok_runtime_art_coverage.py --scan-combat "Champions of Krynn"`. This
reads the three pinned ECL archives, verifies all 22 blocks, and prints the receipt to
stdout. The focused test compares the reproduced receipt when the local archives are present.

The report separates the counts by what they measure:

| Evidence | Current scope |
| --- | --- |
| ECL `PICTURE` sites | 146 sites across 22 verified archive blocks. An exact-site receipt or reviewed host association supplies the source at 26 sites. One operand is dynamic. |
| Representative `COMBAT` rows | 221 entry/site rows at 192 physical sites. Of the retained rows, 38 have no local roster and 101 have alternate paths. The retained rosters include 13 distinct sites with dynamic picture operands. |
| Identified combat picture IDs in the retained paths | 50 of 60 bank-qualified immediate IDs have runtime declarations. CPIC1 contributes 4 of 14, CPIC2 24 of 24, and CPIC3 22 of 22. |
| Attract demo combat | 15 combatant slots, six distinct CPIC2 IDs. This bounded host fixture is counted separately. |
| Runtime declarations | 371 rows, including tiles, icons and components. These point to 334 output paths with 324 distinct hashes. |
| Compositions | Eight player variants and three title screens. Four player variants are admitted and four secondary variants are held. |
| Canonical source IDs | 403 source locators across the current report. Source frame groups retain their registry semantics. |

The combat scanner retains one representative path per entry and offset. It prefers paths
with local rosters and fewer dynamic operands, so an alternate can carry a different
picture operand. The scanner also limits local call depth and queue size. The counts cover
the retained paths and do not measure campaign reachability. For a combat join, the actual
area must select the expected disk and the CPIC archive must match its pinned hash.

Each exact Restyle registry link requires both the source ID and the output SHA-256.
Where an existing runtime output is a different rendition from the gallery record, the
runtime declaration and registry record appear separately. The report also retains the
Amiga portrait #18 candidate locator because its registry identity is still provisional.
Its source and output checks in the runtime code are recorded separately. Candidate IDs,
equal pixels, or matching block numbers cannot fill an unresolved source join.

The local pack audit found 330 matches and four missing paths, all held secondary
`CBODY` variants. Its result measures those local files. Production bundle contents and
browser rendering remain unverified. The source slice preserves the build and browser hold.
