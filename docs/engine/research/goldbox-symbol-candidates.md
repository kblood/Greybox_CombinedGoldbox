## Claim Boundary

A semantic symbol candidate is emitted for a cluster only when CoAB's own oracle map, Pool's own dispatch/replay join, or Secret's own dispatch/replay join reaches that specific cluster hash with an exact or relocation-normalized match -- never from cross-title control-flow-shape similarity alone, and never by assuming a name found for one title also names the same shared function body in another. A `coab_only` cluster keeps its CoAB-sourced name but is not assumed to transfer to Pool, Secret, or any other Gen1 title, even when other titles appear in that cluster's own `call_target_titles` (they call the shared function body; they do not themselves supply naming evidence for it). Every promoted candidate still requires a native CS:IP trace before being called runtime-reached, per the claim boundaries already recorded in the three source reports this tool joins.
