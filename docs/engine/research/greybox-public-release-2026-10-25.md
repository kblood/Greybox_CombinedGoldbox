# Greybox site: artwork, gameplay-data and save-file boundary (2026-10-25)

The user authorized publication of picture assets and, on explicit follow-up, the map and event-script data (`GEO`/`ECL`) required by the existing playable web routes. Original executables/overlay code, drivers, credentials, saved games and character files are **not** part of this authorization. The existing live site was checked by HTTP HEAD before this change: `Champions of Krynn/ECL1.DAX` and `The Dark Queen of Krynn/SAVGAMA.QSV` were both HTTP 200; NWN's bundled manifest existed but its `TITLE.DAX` and `GEO0.DAX` were HTTP 404. The replacement bundle deliberately removes the previously exposed QSV; that is a removal of an old published file, not permission to republish saves.

`apps/web/scripts/public-artifact-policy.mjs` is the fail-closed packaging/audit contract. `bundle-assets.mjs` filters every collection source and bundled manifest, including directories and absolute paths. Original executable/driver types (`EXE`, `COM`, `OVR`, `ADV`, `DLL`, `SYS`), save/character types and paths (`SAVE/`, `SAVGAM*`, `CHRDAT*`, `SAV`, `QSV`, `GAM`, `WIZ`, `JNK`, `EFF`, etc.), and config/key formats are excluded. The audit rejects stale forbidden files or unknown types, rather than deleting them silently. NWN's 29 approved image/data archives may ship, but `GAME.EXE` may not; the production preview reports loot names unavailable instead of fetching the executable. Public save imports require a selected local `AssetSource`; without one they explain the missing save without making a 404 request. The standalone save editor is local-only. Development mode still reads the user's own local saves and executable for its existing tests. This is **not** approval of full cross-platform graphics-mode coverage or any Rust/native release. CoK PIC1 block 58 remains excluded.
