# Secret of the Silver Blades — verified release contract

> Status: selected-folder release contract, 2026-07-28.

The `secret-of-the-silver-blades` profile is promoted only for the evidence below.  This is
not a claim of full-game or pixel-perfect retail parity.  The release input is a real,
user-selected read-only DOS installation; the Electron acceptance path calls native folder
acquisition, preserves that `AssetSource`, and then mounts the independently byte-proven
ECL3/GEO3 Hydra route.

## Checkpoint ledger

- **Detection and Electron:** `electron-secret-verified-route` detects the selected Secret
  folder and mounts from its retained asset source, rather than the repository fixture.
- **Opening dialogue:** Secret's campaign opening/middle evidence is recorded as **Secret's
  Second Route** in `persistent-natural-routes.md`; it is a retail GEO-backed narrative walk,
  not a synthetic menu preview.
- **Town service:** **Secret's Fourth Route (Town Enter/Exit)** proves New Verdigris entry, a
  Marcus/residence action, and the retail exit chain.
- **Wilderness travel:** **Secret's Wilderness/Overland Classification** is a verified negative:
  Secret does not ship the continuous `WILDCOM.DAX` style layer that this checkpoint represents.
  The contract therefore records structural absence, not invented travel support.
- **Quest:** **Secret's Sixth Route (Quest — Cross-Block Persistent Alert Flag)** proves the
  real cross-block setter/read relationship.  Its live UI wiring remains deliberately deferred.
- **Exploration, natural combat, outcome, save/reload, browser:** the browser Hydra test markers
  `secret-natural-target`, `secret-natural-roster`, `secret-natural-resume`, and
  `secret-persistent` execute real selected route bytes and a fresh-page save/load replay.
- **Graphics:** `secret-single-source-graphics` is an explicit constraint check, not a switch
  claim.  The mounted Secret route renders the one calibrated DOS-EGA source and deliberately
  reports no alternate graphics mode.  Multi-source switching remains outside this release
  contract.
- **Companion:** the selected-folder Electron run opens Journal, Reference DB, Automap, HUD, and
  Character panels, verifies populated data and unchanged pose, then continues into combat and
  save/load.

## Boundaries

The capability ledger labels ruleset, graphics, audio, original-save interoperability, towns,
quests, and Companion as partial where appropriate.  In particular, a verified campaign matrix
leg can be engine-evidenced without being promoted as a fully navigable UI sequence.  The
contract is a reproducible release slice, not evidence that every retail screen, rule, or
campaign branch is complete.
